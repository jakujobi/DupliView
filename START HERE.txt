DupliView - Start Here

DupliView is report-only.
It never deletes, moves, renames, overwrites, uploads, or modifies scanned files.

No install is needed on normal Windows 10 or Windows 11 desktop computers.

1. If this came as a ZIP, extract the ZIP first.
2. Keep the extracted DupliView files together in one folder.
3. Open the extracted DupliView folder.
4. Double-click "Run DupliView.cmd".
5. Click "Add Folder".
6. Choose the folder or drive to scan.
7. Keep the default "Reports" folder or choose another export folder.
8. The default "Reports" folder is created when the scan starts.
9. If this folder is read-only, click "Choose Folder" and pick a writable export folder.
10. Review the scan options.
11. Click "Start Scan".
12. Open the CSV report in Excel.

If your computer blocks the launcher, do not disable antivirus.
Ask IT or the repository owner to review the DupliView folder.
For more help, read docs\guides\troubleshooting.md.
